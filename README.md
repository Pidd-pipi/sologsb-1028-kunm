# 组件规范与无障碍说明编辑台（sologsb-1028）

面向设计系统维护者的组件契约编辑台。项目从零搭建，不是单页占位稿；组件、属性、状态、键盘行为、读屏说明、禁用场景和代码示例均使用真实数据模型，并自动保存到浏览器 `localStorage`。

## 功能

- 组件目录与全文搜索：可搜索组件名称、属性、键盘行为、读屏说明和示例代码。
- 分组编辑器：概述、属性与状态、无障碍、关联示例、版本与迁移五个工作区。
- 规范校验：检测重复属性、缺少键盘/读屏说明、空示例、失效属性引用和交互契约变化。
- 跨仓对账闸门：可导入规范包 JSON 或加载内置示例；组件和属性先按标识配对，标识缺失再用名称与类型确认；双端新值、下架碰本地改值、一包多候选必须逐项裁定，未完成不能生成待发布版本。
- 待发布版本与快照：裁定后先生成待发布包；确认发布前不覆盖工作区，发布时为旧版本追加保留快照，下架组件进入归档。
- 属性契约失效传播：属性名、类型、必填、默认值或交互签名变化后，依赖示例与无障碍说明立即标记失效并重算，人工确认后才采用。
- 可恢复离线写入：对账会话、候选裁定、待发布版本和工作区统一写入本地事务；容量不足时整批拒绝，原工作区保留，刷新或关闭页面后可继续。
- 失效传播与迁移：修改交互签名、删除属性或更新组件契约后，关联示例会标记为待迁移；迁移操作可清理已删除属性引用并更新版本。
- 版本差异：保存快照后可比较字段、属性与示例变化；保留最近 12 个快照。
- 主题与密度预览：支持浅色/深色，以及紧凑、标准、宽松三档密度。
- 代码示例复制与离线编辑：内容写入本地存储，刷新或断网后仍可继续编辑。
- 撤销重做：支持工具栏按钮，以及 `Cmd/Ctrl+Z`、`Shift+Cmd/Ctrl+Z`。
- 键盘流程：`Cmd/Ctrl+K` 聚焦搜索，`Alt+1` 至 `Alt+6` 切换编辑区，`Alt+N` 新建组件，`Cmd/Ctrl+S` 保存版本。

## 技术栈

- Lit 3
- TypeScript 5
- Spectrum Web Components
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认在源码配置的 Vite 端口运行，并监听 `0.0.0.0`。宿主机端口由项目根目录的 `docker-compose.yml` 统一映射为 `10028:80`。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1028 .
docker run --rm -p 10028:80 sologsb-1028
```

镜像采用 Node 多阶段构建，最终由 nginx 提供静态内容并监听容器 `80`。容器不硬编码宿主端口。

## 数据说明

浏览器存储键为 `sologsb-1028-workspace-v2`，会兼容读取一次旧的 `v1` 数据。清除站点数据会恢复到内置示例数据。
